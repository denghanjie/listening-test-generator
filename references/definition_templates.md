# Definition Templates Reference

This file contains example definition-recognition templates for Section D.

## Format

Each line: `word | definition sentence`

The student hears the definition and must write the word.

## Starter Templates

monument | A structure built to remember a famous person or event.

craft | An activity involving skill in making things by hand.
legend | A traditional story sometimes popularly regarded as historical.

## Adding Custom Definitions

Add new lines following the same `word | definition` format.
If a word has no custom definition, the generator will auto-create one from the meaning field in the CSV.
